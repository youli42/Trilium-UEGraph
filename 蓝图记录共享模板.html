蓝图记录共享模板

一个用于记录并展示 UE 蓝图节点图的 Trilium 共享模板。把 UE 编辑器里"复制节点"得到的文本当作一份代码笔记保存，本模板会在渲染笔记里自动绘出对应的节点图。

目录结构

蓝图记录共享模板（书，本笔记）
 ├─ 蓝图渲染模板（code/text/html）         ← 渲染界面骨架（工具栏 + 画布 + 源码面板）
 │    └─ 蓝图渲染脚本（code/js）           ← 胶水逻辑：定位记录、读源码、注入引擎、绘制
 ├─ 蓝图渲染资产（书）
 │    ├─ render.js（可留空占位）            ← blueprintUE 渲染引擎
 │    └─ render.css（可留空占位）           ← 样式
 ├─ 使用说明（本笔记）
 └─ 演示·蓝图记录（render 笔记）
      └─ 示例蓝图文本（code/text/plain）    ← 演示用的源码

任何一张「蓝图记录」的形态都是：一个 render 笔记 + 一个子 code 笔记（存 T3D 源码），并把 render 笔记的 ~renderNote 关系指向 蓝图渲染模板。

关键要点

  • ~renderNote：render 笔记指向 蓝图渲染模板的关系。可跨目录引用（放在任何位置都行）。
  • #blueprintText（可选）：指到【存源码的子 code 笔记】。若不设，则自动取 render 笔记下第一个 code 子笔记作为源码。
  • 资产加载：渲染脚本会先用 fs 读取 #renderAssetsDir指向的本地目录里的 render.js/ render.css；读不到时回退到 蓝图渲染资产 下的同名笔记。 #renderAssetsDir目前指向 F:\code\blueprintue-self-hosted-edition\www\bue-render。

如何新建一张蓝图记录

  1. 在目标目录新建一个 render 笔记（类型 render），命名如「某个蓝图」。
  2. 在该 render 笔记下新建一个 code 子笔记（mime 用 text/plain），命名为「蓝图文本」或任意名。
  3. 把 UE 编辑器里选中节点 → 右键「复制(Copy)」得到的整段文本粘贴进该 code 子笔记。
  4. 给 render 笔记加属性：
    • 关系 ~renderNote → 蓝图渲染模板（本库里的 E1T63jd042tq）。
    • （推荐）标签 blueprintText = 源码 code 子笔记的 noteId；不设则自动取第一个 code 子笔记。
  5. 保存，打开 render 笔记即可看到节点图；可切「源码」查看、点「刷新」重画。

输入格式要求

必须是 UE 编辑器「复制节点」生成的 T3D 文本，形如：

Begin Object Class=/Script/BlueprintGraph.K2Node_Event ...

粘贴纯蓝图 JSON、.uasset、粘图片均不生效。若格式不符，画布会显示红色错误提示。

维护

  • 升级渲染引擎：替换 F:\code\blueprintue-self-hosted-edition\www\bue-render 下 render.js/ render.css（或直接更新 蓝图渲染资产里的同名笔记，去掉占位内容）。
  • 脱离本地目录：把 render.js、 render.css的完整内容粘贴进 蓝图渲染资产 下两个同名笔记（替换占位文本），再把 #renderAssetsDir清空。即可完全自包含、不依赖外部路径。
